# FungiBioML_dataset
A fungal SM dataset for bioactivity prediction
---
### Data sources
The curated fungal SM dataset (FungiBioML) is available through Zenodo at [https://doi.org/10.5281/zenodo.22078158]. 
This dataset was constructed based on three publicly available NP resources: 
- ANPDB: [(https://african-compounds.org)].
- EMNPD: [(http://emnpd.idrblab.cn/)].
- Nat-UV DB: [(https://doi.org/10.5281/zenodo.14715820)].
